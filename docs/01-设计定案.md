# 01 · 设计定案（单一事实来源）

> 本文档汇总所有已确认的设计决策。与代码冲突时以本文档为准；修改设计必须先改本文档，再改代码。

## 1. 技术栈

| 层 | 选择 |
|---|---|
| 语言 / 工程 | TypeScript + Vite 模块化 |
| UI | React 组件 + Zustand |
| 游戏渲染 | Canvas 2D 自绘（低分辨率 + `pixelated` 整数放大） |
| 存档 | localStorage + 版本化 JSON |
| 字体 | Fusion Pixel（缝合像素字体，支持中文） |
| 音频 | Web Audio 程序化生成（8-bit 音效 + 每主题 chiptune BGM） |
| 测试 | Vitest |

## 2. 架构总纲

五层解耦：**core（纯逻辑）→ render（纯绘制）→ maps/themes（纯数据）→ ui（React 壳）→ storage（存档）**，另加 boot（加载）。

- 数据流单向：`engine 事件 → 桥接层 → Zustand → React`；React 只能通过 EngineAPI 命令口控制游戏
- 逻辑层永不反向依赖 React；Canvas 内高频状态永不进 React
- 状态机：`BOOTING → MENU → MAP_SELECT → PLAYING ⇄ PAUSED → GAME_OVER`
- 详见 [04-架构设计.md](04-架构设计.md)

## 3. 风格体系：卡通像素

- 五条视觉法则：**2px 粗描边 / 圆角 / 4px 实心硬阴影（不用模糊阴影）/ 有限调色板（每主题 8~10 色）/ Fusion Pixel 字体**
- 深色为主，每张地图一套 token → CSS 变量 → UI 整体换肤
- 动效适中档：200~400ms 统一缓动节奏
- 渲染策略：内部低分辨率（格子 16px，约 320×200 级）→ 整数倍放大
- 详见 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md)

## 4. 地图规格（4 张）

| 地图 | 基调 | 障碍（动态） | 蛇身外观 |
|---|---|---|---|
| 丛林自然 | 墨绿 | 藤蔓柱 · 呼吸开合 | 条纹蛇 + 猫耳头 |
| 暗黑地牢 | 炭黑 | 石墙 · 滑动闸门 | 鳞片蛇 + 龙头 |
| 极简几何 | 深蓝灰 | 棱柱 · 旋转摆动 | 方块蛇 + 机器人头 |
| 深海蓝光 | 深蓝 | 珊瑚漂移 / 水母游动 | 渐变蛇 + 鱼头 |

方形网格、**精致化标准**（纹理 / 细节 / 场景动效 / 氛围音四维度，详见 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md)）；动态障碍运动类型：`pulse / patrol / gate / drift`。
地图差异化维度（已确认）：**配色、背景装饰、障碍布局、蛇身外观**（不含玩法规则差异）。
详见 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md)

## 5. 玩法规则

| 规则项 | 定案 |
|---|---|
| 首发模式 | 经典单人无尽 + 双人合作（同屏） |
| 操控 | P1 = WASD，P2 = 方向键；2 帧输入缓冲；反向忽略；P/Esc 暂停；R 快速重开；M 静音 |
| 计分 | 食物 10 分；连击每 5 个 +1 倍，上限 X5；音效音高随连击上升 |
| 难度 | 休闲 / 标准 / 困难三档预设（初始速度、加速幅度不同） |
| 双人计分 | 各自计分，HUD 双分数 |
| 双人死亡规则 | 蛇死 → 幽灵状态 10 秒 → 复活于安全位置；**等待期间另一条蛇也死 → 当局结束** |
| 复活保护 | 复活后 2 秒保护期（不吃食物、不受伤害） |
| 两蛇互撞 | 互穿不互伤 |
| 死亡判定 | 撞墙 / 撞静态障碍 / 撞动态障碍 / 撞自身（单人）；双人互穿为例外 |
| 胜负 | 单人：蛇死即当局结束；双人：见复活规则 |

具体数值（速度表等）为占位，进入编码后调优。详见 [03-玩法与规则.md](03-玩法与规则.md)

## 6. 体验保障（四条横切保障）

| 保障 | 核心机制 |
|---|---|
| 流畅性 | 固定时间步长 + 渲染插值、静态层离屏预渲染、粒子对象池 + 数量上限、切页签自动暂停、高频状态不进 React |
| 布局 | CSS Grid 三区（HUD / 画布 / 操作栏）、固定宽高比、整数倍缩放、小屏降级、零 layout shift、换肤过渡遮罩 |
| 加载动画 | BOOTING 状态、资源清单 + 真实进度条、字体就绪再进菜单、程序化绘制无图片资源、加载占位 = 最终尺寸 |
| 报错兜底 | Error Boundary + 帧级 try/catch + 全局监听 + 存档校验重建 + 资源降级 + 内联静态提示（五层防线） |

详见 [05-体验保障与性能.md](05-体验保障与性能.md)

## 7. 性能目标

- 保底 60fps；三级画质（高 / 中 / 低）+ 自动降级（连续低帧自动降一档）
- 中档：粒子减半、关背景装饰动效；低档：关粒子、静态背景
- 设置页可手动覆盖画质

## 8. 开发工具链

- F1 调试面板：网格叠加 / 无敌 / 穿墙 / 调速 0.5x~3x / 瞬移 / 刷食物
- MapData / Theme 数据校验器：开发期构建 + 运行期校验，数据写错立刻报错
- Vitest 单测：碰撞 / 转向 / 计分 / 复活 / 存档
- 详见 [06-开发计划与工具链.md](06-开发计划与工具链.md)
