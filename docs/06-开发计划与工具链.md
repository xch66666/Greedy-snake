# 06 · 开发计划与工具链

## 1. 开发工具链

### 1.1 F1 调试面板

| 功能 | 说明 |
|---|---|
| 网格叠加 | 显示逻辑网格（对位检查） |
| 无敌模式 | 撞墙/障碍/自身不死（单人） |
| 穿墙模式 | 无视边界 |
| 调速 | 0.5x ~ 3x 游戏速度（调手感、调动画） |
| 瞬移 | 点击格子放置蛇头 |
| 刷食物 | 指定位置生成食物 |
| 幽灵/复活调试 | 双人模式下强制触发死亡→复活流程，验证 10 秒等待与双死判定 |

仅开发构建启用（`import.meta.env.DEV`），生产构建不打包。

### 1.2 数据校验器（validate.ts）

- 校验对象：`MapData`、`Theme`（及动态障碍参数）
- 时机：开发模式构建期校验 + 运行期 DEV 校验 + 存档读入校验
- 效果：地图/主题数据写错（越界格子、重复障碍、非法 motion 值、调色板超 10 色等）→ 开发期立刻报错，防"数据写错全盘炸"
- 新增地图的底气：改数据文件即可，校验器保证不炸

### 1.3 单元测试（Vitest）

覆盖范围（全部为纯逻辑层，无 DOM）：

| 模块 | 用例示例 |
|---|---|
| snake.ts | 移动、转向、反向忽略、增长 |
| collision.ts | 撞墙 / 撞障碍 / 撞自身 / 双人互穿 |
| revive.ts | 10 秒等待、双死结束、2 秒保护期、安全复活点 |
| scoring.ts | 基础分、连击倍率（每 5 个 +1，上限 X5）、断连重置 |
| food.ts | 不与蛇/障碍重叠、种子可复现 |
| save.ts | 读写、版本迁移、坏档重建 |
| maps/* | 校验器通过、出生点可达、无重叠障碍 |

## 3. 完成定义（Definition of Done）

1. 四个模式入口可用：单人/双人 × 任意地图 × 三档难度
2. 60fps 保底，自动降级生效
3. 四张地图风格可辨识，UI 换肤正确
4. 复活规则全场景正确（等待 / 双死 / 保护期 / 互穿）
5. 存档：写入、读取、损坏重建、删除 全部可用
6. 报错兜底：组件崩溃、帧异常、坏档均有友好提示，不白屏
7. 单测全绿；数据校验器零报错
8. 无控制台报错（开发环境）

## 5. 变更管理约定

1. 改设计 → 先改 docs 文档 → 再改代码
2. 改规则 → 同步改 03 文档 + 补/改 Vitest 用例
3. 改类型签名 → 必须同步 04 文档的接口草案
4. 新增地图 → 2 个数据文件 + 校验通过，不动逻辑
