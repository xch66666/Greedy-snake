# 05 · 体验保障与性能

> 四条横切保障：**流畅性 / 布局与自适应 / 加载动画 / 报错兜底**，加性能目标。这些是"游戏和界面都舒服"的底线，属于架构承诺，不是某个模块的事。

## 1. 流畅性保障

### 1.1 游戏侧（Canvas）

| 机制 | 说明 |
|---|---|
| 固定时间步长 + 渲染插值 | 蛇按 tick 推进逻辑，渲染帧在两格间插值，蛇头滑动而非跳格——流畅的第一来源 |
| 统一时间源 | 全部使用 `performance.now()`，蛇与动态障碍共用，无多时钟错位 |
| 切页签自动暂停 | `visibilitychange` 时暂停并记录，避免切回后 delta 爆炸导致瞬移/卡顿 |
| 粒子对象池 + 数量上限 | 复用粒子实例避免 GC 卡顿；单帧粒子数封顶，华丽特效也稳帧率 |
| 静态层离屏预渲染 | 网格线、背景装饰、静态障碍只画一次；每帧只重绘动态内容 |
| 转向平滑 | 蛇头朝向角度插值过渡，非瞬间 90° 跳变 |

### 1.2 UI 侧（React）

| 机制 | 说明 |
|---|---|
| 状态不进 React 铁律 | Canvas 内高频状态不进 React；分数、连击等低频事件才进 Zustand，不触发整树重渲染 |
| 高频组件 memo | HUD 等高频更新组件用 `memo` 隔离渲染范围 |
| 合成器动画 | 面板动画一律 `transform` + `opacity`（合成器线程，不触发重排） |
| 字体防跳动 | `font-display: swap` + 加载完成后全局切换，避免 FOUT |

## 2. 布局与自适应

| 机制 | 说明 |
|---|---|
| 三区布局 | CSS Grid：顶部 HUD 条（分数/连击/地图名）→ 中部画布（固定比例居中）→ 底部操作栏；任何窗口尺寸结构不变 |
| 固定宽高比 | 游戏区容器 `aspect-ratio` 固定，不随窗口拉伸变形 |
| 整数倍缩放 | 像素画布按 JS 计算的最佳整数倍放大，不糊不抖 |
| 小屏降级 | HUD 次要信息（连击提示等）小屏隐藏，画布优先占满；禁止页面滚动（`overflow: hidden`），游戏页始终沉浸 |
| 零 layout shift | 加载动画占位尺寸 = 最终游戏区尺寸，资源到位后原位替换 |
| 换肤过渡 | 切地图用 300ms 覆盖层过渡，避免配色瞬间切换的突兀与闪白 |

## 3. 加载动画

加载是状态机的第一站（BOOTING），按资源清单管理：

| 机制 | 说明 |
|---|---|
| 资源清单 + 真实进度 | 字体等资源 `Promise.all` 并行加载，动画显示真实进度（像素风进度条），不造假进度 |
| 启动时序 | 先出 Logo + 加载动画（UI 壳零依赖立刻可画）→ 资源就绪 → 淡入主菜单 |
| 程序化绘制红利 | 主题全是程序化绘制，天然无图片资源，加载清单极短（主要是字体） |
| 按需加载 | 未来若加图片资源：选图时按需加载 + 该图转场动画 |
| 字体就绪 | `document.fonts.ready` 等待就绪再进主菜单，杜绝菜单字体"半加载"丑态 |

## 4. 报错兜底（五层防线，任意一层失效都不白屏）

| 层级 | 兜底手段 |
|---|---|
| React UI | **Error Boundary** 包住各界面：任一组件崩溃 → 像素风错误卡片（"出错了，重新加载 / 返回菜单"），绝不整页白屏 |
| 游戏循环 | 单帧 `try/catch`：单帧异常记录并跳过继续跑；连续 N 帧失败 → 停止循环，弹出"游戏遇到问题"重试面板，回到 MENU 而非黑屏 |
| 全局 | `window.onerror` + `unhandledrejection` 监听：非致命错误转 toast 提示，不打断游戏 |
| 存档 | 读写全 try/catch + schema 校验：坏档不崩溃，提示"存档损坏"并提供"重建默认存档" |
| 资源 | 字体加载失败 → 静默回退系统字体（不报错不阻塞）；任何资源失败都有降级路径 |
| 终极 | `index.html` 内联最小静态提示 + `noscript`：即使 JS 完全挂掉，页面也显示"加载失败，请刷新"而非纯白屏 |

统一出口：`errorReporter.ts`——开发环境打印堆栈，生产环境收敛为友好提示；未来接上报只改这一个文件。

## 5. 性能目标与降级

| 项 | 定案 |
|---|---|
| 目标 | 保底 60fps |
| 三级画质 | 高 / 中 / 低（设置页可手动覆盖） |
| 中档 | 粒子减半、关闭背景装饰动效 |
| 低档 | 关闭粒子、背景静态化 |
| 自动降级 | 帧率检测：连续 30 帧低于 50fps → 自动降一档并提示（可关闭自动降级） |

## 6. 新增模块清单（相对既有架构）

```
src/boot/      loadingManager.ts          ← 新增（加载）
src/ui/        ErrorBoundary.tsx / ErrorCard.tsx  ← 新增（兜底）
src/core/      errorReporter.ts           ← 新增（错误出口）
src/render/    staticLayer.ts             ← 明确职责（离屏预渲染）
```

其余全部落在既有层的接口约定里（统一时间源、整数倍缩放、状态机加 BOOTING 态）。
