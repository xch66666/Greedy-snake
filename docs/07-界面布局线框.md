# 07 · 界面布局线框（wireframe）

> 本文档定义各界面的**布局结构**（区域划分、元素位置、信息层级），不含视觉细节。
> 视觉细节（配色/字体/圆角/动效）以 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md) 为准。
> 所有界面为深色底 + 像素风 + 硬阴影按钮；颜色全部来自 CSS 变量（跟随地图主题换肤）。

## 0. 三层导航结构（核心布局理念）

仿 Minecraft 式布局：**入口极简，设置不占层，流程最短**。

```
第 1 层  主菜单（界面极简，只有页面中间一列按钮）
            │ 单人游戏 / 双人游戏        │ 设置
            ▼                           ▼
第 2 层  选图界面（4 张地图卡片 + 难度）   设置弹窗（模态覆盖，不离开主菜单）
            │ 开始游戏
            ▼
第 3 层  游戏界面（HUD 条 + 画布 + 操作栏）
            │ 暂停（覆盖层）
            ▼
        暂停菜单（继续 / 设置 / 重开 / 返回选图）
```

- 主菜单 → 设置：**弹窗**，不切换页面，Esc 关闭
- 主菜单 → 单人/双人：进入选图，**模式已在第一层定死**，选图界面不再选模式
- 选好地图 → 直接开始游戏（第三层），无中间确认页
- 加载（BOOTING）、暂停、结算均为覆盖层/过渡状态，不占导航层

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│            🐍 像素贪吃蛇                      │
│              Pixel Snake                     │
│                                              │

│           └────────────────┘                 │
│           ┌────────────────┐                 │
│           │   双人游戏      │                 │
│           └────────────────┘                 │

│                                              │
│        v1.0 · 本地存档 · 4 张地图              │
```

布局规则：
- **页面整体极简**：只有页面中间的一列按钮（单人游戏 / 双人游戏 / 设置），无侧栏、无装饰性元素
- Logo（像素字体大标题 + 英文副标）在按钮列上方，居中对齐
- 按钮列垂直居中于页面；按钮等宽、间距统一
- 底部一行小字版本信息，不抢视觉
- 背景：当前主题的程序化背景（轻微动态），菜单本身无其他内容

## 2. 设置弹窗 SETTINGS（模态，从主菜单弹出）

```
┌──────────────────────────────────────────────┐
│                设 置                          │
│                                              │
│   音效音量    ▓▓▓▓▓▓▓░░░░  70%               │
│   音乐音量    ▓▓▓▓▓▓░░░░░  50%               │
│   画质        (●)高  ( )中  ( )低            │
│   难度        (●)休闲 ( )标准 ( )困难         │
│   自动降级    [✓] 开启                        │
│   ─────────────────────────                  │
│   [ 删除存档 ]                                │
│                                              │
│              ┌────────────┐                  │
│              │  返回       │                  │
│              └────────────┘                  │
└──────────────────────────────────────────────┘
```

规则：
- **模态弹窗**：覆盖在主菜单上方，背景暗化 40%，不离开主菜单
- Esc 或"返回"关闭；弹窗尺寸固定（约 480×420 逻辑像素）
- 内容：音效/音乐音量滑条、画质三档、难度三档、自动降级开关、删除存档（危险操作，点击后二次确认）
- **同一弹窗在游戏内暂停菜单中复用**（暂停菜单 → 设置），返回时回到暂停菜单
- 所有设置在弹窗内即时生效并持久化到存档

## 3. 第 2 层 · 选图界面 MAP_SELECT

```
┌──────────────────────────────────────────────────┐
│  ← 返回         单人游戏 · 选择地图               │
│                  难度: (●)休闲 ( )标准 ( )困难     │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐│
│ │ 丛林自然  │ │ 暗黑地牢  │ │ 极简几何  │ │ 深海蓝光  ││
│ │  [缩略图] │ │  [缩略图] │ │  [缩略图] │ │  [缩略图] ││
│ │ 最高分200 │ │ 最高分150 │ │ 最高分 90 │ │ 最高分120 ││
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘│
│  选中卡片: 高亮描边 + 轻微上浮                        │
│                    ┌────────────┐                  │
│                    │  开始游戏   │                  │
│                    └────────────┘                  │
└──────────────────────────────────────────────────┘
```

规则：
- 顶部：返回按钮 + **模式标签**（"单人游戏 / 双人游戏"，由第一层决定，不可在此更改）+ 难度切换
- 4 张地图卡片 2×2 网格；卡片 = 地图名 + 程序化缩略图（真实地图数据小样）+ 最高分
  - 单人模式显示单人最高分；双人模式显示双人合计最高分
- 选中卡片：高亮描边 + 上浮；切换选中时整页预览换肤（300ms 过渡）
- 底部"开始游戏"主按钮：点击 → 加载地图（转场遮罩 300ms）→ 进入游戏
- 难度默认取设置弹窗中的难度值，可在本页临时切换（本局生效）

## 4. 第 3 层 · 游戏界面 PLAYING

### 4.1 单人

```
┌──────────────────────────────────────────────┐
│  分数 240 · x2  │ 丛林自然·标准·单人 │ P:暂停  │ ← HUD 顶部条
├──────────────────────────────────────────────┤
│                                              │
│         ┌────────────────────┐               │
│         │                    │               │
│         │     游戏画布        │               │
│         │  (固定宽高比居中)    │               │
│         │                    │               │
│         └────────────────────┘               │
│                                              │
│     WASD 移动 · R 重开 · M 静音               │ ← 操作栏底部
└──────────────────────────────────────────────┘
```

- HUD 三列：**左 = 分数 + 连击倍数**（x2…x5）｜**中 = 地图名 + 难度 + 模式**｜**右 = 快捷键提示**
- 分数跳动动画（200ms），连击倍率变化时强调闪烁

### 4.2 双人（HUD 变化 + 复活浮条）

```
│  P1 180 · x2  │ 双人·深海蓝光·标准 │ P2 240 · x3 │ ← 左右各一个分数
├──────────────────────────────────────────────┤
│          ┌──────────────────────────┐         │
│          │  💀 P2 幽灵中 · 复活 7s   │         │ ← 复活浮条(画布上方)
│          │  （期间 P1 死亡则结束）    │         │
│          └──────────────────────────┘         │
```

- HUD 左右分列 P1/P2 分数（各自计分），中间地图名 + 模式 + 难度
- 蛇死亡 → 画布上方中央出现**复活倒计时浮条**（10 秒倒计时，实时更新）
- 双死 → 直接进入结算界面

## 8. 界面与主题换肤的对应关系

| 界面元素 | 取色来源（CSS 变量） |
|---|---|
| 背景 / 网格装饰 | `--bg` / `--grid` |
| 按钮 / 卡片 | `--accent`（主按钮）/ 半透明深色（次按钮） |
| 文字 | `--ui-text` |
| 描边 / 硬阴影 | `--outline` / `--shadow` |
| 蛇 / 食物（画布内） | `--snake-a` / `--snake-b` / `--food` |

> 所有界面共享同一套 CSS 变量 → 切地图 = 换整套 UI 皮肤，界面布局零改动（与 02 文档一致）。
