# 13 · 相机增强：双人动态缩放 + 食物导航指示器

> 用户需求：① 双人视角看不到自己的蛇 → 动态缩放；② 地图大找不到果子 → 导航指向。

## 1. 双人动态缩放（docs/11 相机扩展）

| 项 | 规格 |
|---|---|
| 单人 | 视野固定 24×18 格（384×288），跟随蛇头 |
| 双人 | 视野 = 两蛇包围盒 + 5 格边距，保持 4:3，**平滑插值**（dt×3） |
| 范围 | 最小 20×15 格（放大）~ 最大 40×30 格（拉远），封顶防过度缩小 |
| 画布 | 每帧按整数格自适应（20×15~40×30 格 × 16px），`pixelated` 整数倍放大保持锐利 |
| 相机 | 跟随两蛇中点，边界 clamp（视野不超出地图） |

- 效果：双蛇聚拢 → 自动放大看清细节；双蛇分离 → 自动拉远双方尽收眼底
- 纯函数：`calcCoopView(boxW, boxH, margin)`（src/render/camera.ts），单测覆盖（比例/封顶/横向主导）

## 2. 食物导航指示器

| 项 | 规格 |
|---|---|
| 触发 | 食物中心在视野外（含 16px 边距） |
| 显示 | 视野边缘内缩 12px 处：**食物色三角箭头**（指向食物方向，深色描边保证任何背景下可见）+ **脉动食物色圆点**（3.5px，4Hz 脉动） |
| 位置计算 | 从视野中心到食物方向的射线与画布矩形边缘求交 |
| 绘制 | 屏幕空间（相机平移之后），位于 vignette 之前 |
| 多食物 | 逐个绘制（本期场上 1 个，未来多个全显示） |

- 效果：果子在屏幕外时，边缘箭头永远指向它，不再大海捞针
- 单人/双人均生效

## 3. 实现位置

- `src/render/camera.ts`：`calcCoopView` / `MIN_VIEW_W` / `MAX_VIEW_W` / `VIEW_ASPECT`
- `src/render/renderer.ts`：动态视野（`viewW/viewH` 平滑 + canvas 自适应）、`drawFoodIndicators`
- 测试：`src/render/camera.test.ts`（6 用例）；E2E 断言双人 canvas 宽 > 384（实测 640px）
