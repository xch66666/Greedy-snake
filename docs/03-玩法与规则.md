# 03 · 玩法与规则

## 1. 游戏模式（首发两个）

| 模式 | 说明 | 控制 |
|---|---|---|
| 经典单人无尽 | 单蛇吃食物，蛇死当局结束 | P1：WASD |
| 双人合作 | 两蛇同屏一起吃食物，各自计分 | P1：WASD，P2：方向键 |

> 限时 / 关卡 / 对战模式为后置项，不在本期范围（见 06 文档）。

## 2. 操控手感

| 机制 | 定案 |
|---|---|
| 输入缓冲队列 | 每蛇 2 帧缓冲，快速连按两个方向不吞键 |
| 反向忽略 | 180° 转向输入直接丢弃（防自杀误触） |
| 暂停 | P / Esc（暂停菜单：继续 / 重开 / 返回选图） |
| 快速重开 | R 键 |
| 静音 | M 键（与设置面板音量联动） |

## 3. 计分系统

| 规则 | 定案 |
|---|---|
| 基础分 | 每个食物 10 分 |
| 连击 | 每连续吃 5 个 +1 倍，上限 X5（断连重置） |
| 连击反馈 | 音效音高随连击上升；HUD 显示连击倍数 |
| 双人 | 各自计分，HUD 双分数显示（P1 / P2） |

## 4. 难度曲线（三档预设）

| 档位 | 初始速度 | 加速幅度 | 封顶速度 |
|---|---|---|---|
| 休闲 | 4 格/秒 | 每 8 个食物 +0.4 格/秒 | 8 格/秒 |
| 标准 | 6 格/秒 | 每 6 个食物 +0.5 格/秒 | 11 格/秒 |
| 困难 | 8 格/秒 | 每 5 个食物 +0.6 格/秒 | 14 格/秒 |

> 以上为**已实现初值**（src/game/core/constants.ts），手感调优后最终值回填本表。加速按"吃食物数量"平滑触发，封顶后不再加速。
> 双人合作模式沿用所选档位，两蛇速度曲线相同。

### 数值状态清单（已定死 vs 待调优）

| 状态 | 项 |
|---|---|
| ✅ 已定死 | 食物 10 分；连击每 5 个 +1 倍、上限 X5；场上食物 1 个；三档难度存在；双人 10 秒复活等待；复活 2 秒保护；互穿不互伤 |
| ⏳ 待调优（已实现初值，手感验证后最终确定） | 三档速度曲线（4/6/8 初始 · 封顶 8/11/14）；连击音高爬升曲线 |

> 规则层四张地图完全统一；地图间唯一机制差异 = 动态障碍运动类型（见 02 文档第 6 节）。

## 5. 死亡与复活规则

### 5.1 死亡判定

- 撞墙（地图边界）
- 撞静态障碍 / 撞动态障碍
- 撞自身身体
- 双人例外：**两蛇互撞 → 互穿不互伤**（合作模式的唯一豁免）

### 5.2 单人模式

- 蛇死亡 → 当局结束 → GAME_OVER 结算画面（本图最高分记录，破纪录高亮）

### 5.3 双人合作模式（核心规则）

```
任一蛇死亡
   │
   ├─► 死亡蛇进入【幽灵等待】状态，倒计时 10 秒
   │     · 幽灵期间不可操作、不产生碰撞
   │     · HUD 显示复活倒计时
   │
   ├─► 等待期间另一条蛇也死亡 → 【当局结束】（双死判定）
   │
   └─► 10 秒倒计时结束 → 复活于安全位置
         · 安全位置 = 远离障碍、远离另一条蛇、不与食物重叠的格子
         · 复活后进入【保护期】2 秒：不吃食物、不受伤害
         · 保护期结束 → 恢复正常游戏
```

| 子状态 | 时长 | 行为 |
|---|---|---|
| ALIVE | — | 正常移动、吃食物、可死亡 |
| GHOST_WAITING | 10 秒 | 不可操作；期间另一条蛇死亡 → 当局结束 |
| INVINCIBLE | 2 秒 | **原地无敌**（不移动、不吃食物、不受伤害，docs/13 修订：防"活了就死"） |

> 单人模式不启用复活机制；双人模式中"两蛇互穿不互伤"意味着蛇只能因墙 / 障碍 / 自身死亡。

## 6. 状态机

```
BOOTING → MENU → MAP_SELECT → PLAYING ⇄ PAUSED → GAME_OVER
                                  │
                                  └── 蛇状态：ALIVE / GHOST_WAITING / INVINCIBLE
```

| 状态 | 说明 |
|---|---|
| BOOTING | 加载动画（资源清单 + 真实进度条），字体就绪后进入 MENU |
| MENU | 主菜单：开始游戏 / 设置 / 关于 |
| MAP_SELECT | 选图 + 选难度（**模式已在主菜单选定**，选好图直接开始游戏） |
| PLAYING | 游戏运行；内部含蛇的子状态机 |
| PAUSED | P/Esc 暂停；菜单：继续 / 重开 / 返回选图 |
| GAME_OVER | 结算：单人显示分数与最高分；双人显示双方分数与胜者（分数高者，平局显示平局） |

## 7. 单局流程

```
选图 → 选模式（单人/双人）→ 选难度 → 加载地图（转场遮罩 300ms）
  → PLAYING（开始：3-2-1 倒计时或直接开始 [待定，默认直接开始]）
  → 循环：移动 → 转向 → 吃食物（计分/连击/粒子/音效）→ 死亡判定
  → 单人：GAME_OVER 结算 → 快速重开（R）/ 返回选图
  → 双人：死亡 → 复活流程 → 双死 → GAME_OVER 结算
```

## 8. 食物规则

- 场上食物数量：默认 1 个（可随地图配置，本期统一 1 个）
- 生成位置：不与蛇身、障碍、另一条蛇重叠的随机空格
- 被吃后立即重新生成

## 9. 音效与音乐（体验维度，规则无关）

| 项 | 定案 |
|---|---|
| 音效 | 吃食物（音高随连击上升）/ 死亡 / 连击 / UI 点击 / 切图 / 复活，Web Audio 程序化生成 |
| BGM | 每主题一套程序化 chiptune 循环，跟随地图换肤（换图 = 换曲） |
| 氛围音 | 每主题一套程序化环境音（丛林=虫鸣鸟叫 / 地牢=滴水火把 / 几何=电子脉冲 / 深海=气泡鲸鸣），与 BGM 同属音乐音量通道 |
| 同步触发 | 音效与动画同步（粒子爆发瞬间发声），详见 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md) 3.4 |
| 设置 | 音效 / 音乐（含氛围音）双音量滑条 + M 静音，持久化到存档 |

## 10. 规则变更流程（重要约定）

任何规则调整（数值、复活时长、连击倍率等）：
1. 先改本文档（及 01 定案汇总）
2. 再改代码
3. 涉及纯逻辑的改动同时补 Vitest 用例
