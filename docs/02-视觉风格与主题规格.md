# 02 · 视觉风格与主题规格

## 1. 风格定义：卡通像素

"卡通像素" = 像素感（格子感、像素字体、硬边缘）+ 卡通感（粗描边、圆角、夸张造型）。

### 1.1 五条视觉法则（全游戏统一，风格统一的保证）

| # | 法则 | 规则 | 技术实现 |
|---|---|---|---|
| 1 | 粗描边 | 蛇身、障碍、UI 卡片统一 2px 深色描边 | 绘制统一用主题 `outline` 色 |
| 2 | 圆角 | 所有形状圆角化（像素级圆角） | Canvas `roundRect`；UI `border-radius` |
| 3 | 硬阴影 | 用"偏移实心块"阴影，禁用模糊阴影 | Canvas 画 offset 矩形；UI `box-shadow: 4px 4px 0` |
| 4 | 有限调色板 | 每主题固定 8~10 色，绝不超出 | 主题 token 即完整色板，渲染只认它 |
| 5 | 像素字体 | 全站唯一字体 Fusion Pixel（支持中文） | CSS `@font-face` 全局引入，`font-display: swap` |

### 1.2 配色基调

- 深色为主，**每张地图一套主题 token → CSS 变量 → UI 整体换肤**
- 换图 = 换整套皮肤（背景、按钮、HUD、BGM、氛围音同步切换）
- 切图换肤用 300ms 覆盖层过渡，避免配色瞬间切换的突兀

### 1.3 动效节奏（适中档）

- 全站统一：短 200ms / 中 300ms / 长 400ms（误差 ±50ms）
- 统一缓动函数库（easing.ts），UI 与游戏内动效同节奏
- 动效类型：吃食物粒子爆发、连击数字跳动、死亡碎裂、UI 弹入（easeOutBack）

### 1.4 风格量化规范（像素级，防风格漂移）

> 五条法则 + 全局参数的具体数值。**所有界面、所有主题必须严格遵守**，由数据校验器强制检查（见 06 文档）。任何调整必须改本文档后再改代码。

| 规范项 | 全局值 | 强制方式 |
|---|---|---|
| 粗描边 | 2px 实心，色 = 主题 `outline` | 校验器 |
| 圆角 | 画布内 4px（16px 格的 1/4）；UI 8px | 校验器（radius 全局唯一值） |
| 硬阴影 | offset 4px，不透明色（outline 或 bg 加深 30%） | 校验器 |
| 字体 | Fusion Pixel 12px；标题 24px；行高 1.5 | 全局常量 |
| 动效时长 | 200 / 300 / 400ms ±50ms | 校验器（anim.dur 范围） |
| 缓动 | 弹入 easeOutBack；淡入淡出 easeOutQuad | easing.ts 唯一来源 |
| 调色板 | 每主题 8~10 色，bg 为最深色，语义槽齐全 | 校验器 |
| 装饰实例数 | 每主题 20~60 | 校验器（bgDecor 数量范围） |
| 视差层 | 固定 3 层 | 校验器 |
| 文字对比度 | UI 文字与背景对比度 ≥ 3:1 | 校验器（可算近似亮度差） |

## 2. 渲染策略（像素感的灵魂）

1. **内部低分辨率渲染**：游戏画在离屏 Canvas，格子固定 16px（与星露谷 16px tile 同规格，细节容量最大），整图 768×576（网格 48×36，docs/09/11）
2. **视野与相机**：显示视野 24×18 格（384×288），`image-rendering: pixelated` 整数倍放大；相机平滑跟随蛇（solo=蛇头 / coop=两蛇中点），边界 clamp，滚动探索大地图
3. **静态层离屏预渲染**：纹理、网格线、地表、实体只画一次（整图）；每帧只重绘视野内蛇 + 动态障碍 + 食物 + 粒子 + 装饰动画
4. **插值动效**：蛇与动态障碍在两格间位置插值，蛇头朝向角度插值过渡

> 精细度参考：星露谷物语风格技法——轮廓描边 + 明暗分区（左下暗面/右上高光）+ 纹理细节点 + 多层色。

### 2.1 素材贴图模式（试点：丛林地图）

- 地表可用 CC0 素材表平铺（`Theme.sprites` 可选字段）：`src/assets/sprites/roguelikeSheet.png`（Kenney CC0，16×16 与格子 1:1）
- 平铺按 `decorSeed` 随机取瓦片变体，相邻格避免同变体（星露谷式地表纹理变化）
- 素材经 boot 资源清单预加载（进度条真实显示）；加载失败自动回退程序化底纹
- 实体（树/石等）仍为程序化绘制；后续可扩展实体贴图映射

## 3. 精致化规格（"不粗糙"的承诺）

> 四维度标准：**纹理 / 细节 / 场景动效 / 氛围音**。全部程序化生成（零图片资源），由主题数据驱动。
> 样板先行：先完成 1 张地图（推荐深海蓝光，四维度最典型）全流程精致化，验证观感与性能后，方法论复制到其余 3 张。

### 3.1 纹理

| 机制 | 说明 |
|---|---|
| 主题底纹 | 每主题程序化底纹：丛林=叶片暗纹+光斑；地牢=石砖缝+裂纹；几何=渐变网格；深海=波纹+光柱 |
| 色带消除 | 低分辨率渐变用有序抖动（ordered dithering），避免色带 |
| 接触阴影（AO） | 障碍底部与相邻格接触处生成程序化阴影，增强立体感 |
| 确定性纹理 | 每格纹理由 `decorSeed` 驱动，稳定不闪烁 |
| 离屏预渲染 | 全部纹理一次生成到静态层，每帧零成本 |

### 3.2 细节

| 机制 | 说明 |
|---|---|
| 三层视差背景 | 远景（雾气/星空）→ 中景（树冠/岩壁/几何体/水幕）→ 前景装饰；蛇移动时各层微幅偏移 |
| 装饰元素 | 每主题 2~3 种（见 5.2 速览表），独立动画周期 |
| 蛇身细节 | 花纹（条纹/鳞片/方块/渐变）+ 卡通头（眼睛、吃食物张嘴动画） |
| 食物造型 | 像素造型（浆果/宝石/能量块/珍珠），轻微呼吸动画 |
| 网格线弱化 | 主题色半透明细线，不抢画面 |

### 3.3 场景动效

| 机制 | 说明 |
|---|---|
| 装饰动画 | 确定性周期函数（sin/cos 组合），每元素独立相位，CPU 开销可忽略 |
| 环境光脉动 | 缓慢明暗周期 8~15s，几乎不可察觉的"活"感 |
| 主题边缘光 | 主题色渐变暗角（vignette） |
| 事件反馈链 | 吃食物=粒子+波纹+音效同步；连击=微闪屏；死亡=碎裂+轻震+0.3s 慢动作；复活=圣光粒子 |
| 障碍细节动画 | 在 motion 基础上叠加：藤蔓摆动、火焰摇曳、棱柱旋转、水母触须 |

### 3.4 氛围音（场景声效）

- 每主题一套程序化环境音（见 5.2 速览表），Web Audio 合成（振荡器 + 噪声源 + 滤波），零音频文件
- 音量分层：氛围音归**音乐音量**通道；事件音效（吃/连击/死亡/UI）归**音效音量**通道
- 音效与动画**同步触发**（粒子爆发瞬间发声）

### 3.5 性能与工程保障

- 静态内容（纹理/背景/装饰基座）→ 离屏预渲染一次
- 装饰元素数量封顶（每主题 ≤ 60 实例）+ 对象池
- 三级画质：高=全部开启；中=粒子减半、装饰减半、关视差；低=关装饰动画与氛围音、静态背景

### 3.6 主题自检表（每张地图必须全过，防"发挥不一致"）

> 四张图共用同一张检查表 → 精致度一致性的保证。样板图（深海蓝光）先全过并作为标尺，其余图逐图对照。

| # | 检查项 | 标准 |
|---|---|---|
| 1 | 色板 | 8~10 色，语义槽齐全（bg/grid/border/accent/food/snakeA/snakeB/obstacle/outline/uiText） |
| 2 | 基础规范 | 描边 2px / 圆角 4px / 硬阴影 4px（1.4 表） |
| 3 | 底纹 | 主题底纹 + 有序抖动 + 接触阴影（AO） |
| 4 | 视差 | 三层齐全（远景/中景/前景），偏移量在全局范围 |
| 5 | 装饰 | ≥ 2 种元素，实例数 20~60，动画周期独立 |
| 6 | 场景动效 | 环境光脉动 + 主题边缘光 + 障碍细节动画 |
| 7 | 事件反馈链 | 吃（粒子+波纹+音效）/ 连击（微闪屏）/ 死亡（碎裂+震动+慢动作）/ 复活（圣光）完整 |
| 8 | 蛇身 | 花纹 + 卡通头（眼睛/张嘴动画） |
| 9 | 食物 | 像素造型 + 呼吸动画 |
| 10 | 氛围音 | ≥ 2 种声音元素，与 BGM 分通道 |
| 11 | UI 换肤 | 换肤后文字对比度 ≥ 3:1，按钮/卡片观感与其余主题一致 |
| 12 | 性能 | 该图在高画质下 60fps 达标 |

## 4. 主题接口草案（编码阶段第一步正式化）

```ts
interface Theme {
  id: string
  palette: {
    bg: string            // 深色基调
    grid: string          // 网格线
    border: string        // 地图边框
    accent: string        // 强调色
    food: string          // 食物色
    snakeA: string        // P1 蛇身
    snakeB: string        // P2 蛇身
    obstacle: string      // 障碍色
    outline: string       // 粗描边色
    uiText: string        // UI 文字色（CSS 变量透传）
  }
  shadow: { offset: number; color: string }   // 硬阴影
  radius: number                              // 圆角
  texture: {
    base: "leaf" | "stone" | "gradient" | "wave"   // 底纹类型
    dither: boolean                                // 有序抖动
    ao: number                                     // 接触阴影强度
  }
  bgDecor: DecorSpec[]                        // 背景装饰规格（类型/数量/周期）
  parallax: { layers: number; depth: number } // 视差层数与每层偏移量
  obstacleStyle: "vine" | "stone" | "prism" | "coral"
  snakeStyle: {
    pattern: "stripe" | "scale" | "block" | "gradient"
    head: "cat" | "dragon" | "robot" | "fish"
  }
  anim: {
    eatParticle: "leaf" | "ember" | "shard" | "bubble"
    dur: number
  }
  foodStyle: "berry" | "gold" | "energy" | "pearl"  // 食物造型（docs/09）
  audio: {
    bgm: { tempo: number; scale: string }        // chiptune 参数
    ambient: "insects" | "dungeon" | "pulse" | "abyss"  // 氛围音类型
  }
}
```

> 注意：蛇身外观差异（花纹 + 卡通头）由 `snakeStyle` 决定，两个玩家的蛇各用主题下的不同配色。

## 6. 动态障碍规格

障碍"动态为主"，四种运动类型，全部由逻辑层统一更新（与蛇同一套"逻辑更新 + 渲染插值"机制）：

| motion | 行为 | 用于 |
|---|---|---|
| `pulse` | 原地呼吸（占格数周期缩放/隐现） | 丛林藤蔓柱 |
| `patrol` | 沿路径往返巡逻 | 极简棱柱 |
| `gate` | 闸门式开合（阻挡/放行通道） | 地牢石墙 |
| `drift` | 缓慢漂移（周期往复） | 深海珊瑚 / 水母 |

> 精致化要求：每种 motion 叠加主题细节动画（见 5.2"障碍细节动画"行），逻辑层只算位置，视觉层负责细节。

## 7. 地图数据草案（与 04 架构一致）

```ts
interface MapData {
  id: string
  name: string
  grid: { w: number; h: number }        // 方形网格
  spawn: { x: number; y: number }       // 出生点
  staticObstacles: Cell[]               // 静态障碍
  dynamicObstacles: DynamicObstacle[]   // 动态障碍
  themeId: string                       // 只引用主题，不内嵌任何绘制信息
  decorSeed: number                     // 背景装饰随机种子
}
```
