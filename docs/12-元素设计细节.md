# 12 · 元素设计细节（地板 / 障碍 / 地形）

> 每个元素的独立设计规格：形状（ASCII 格阵）、配色、绘制细节、语义。
> 形状**不限于矩形**（任意相对坐标组合）；障碍**不限于立起物体**，也可以是地形（水塘/荆棘/熔岩等平铺地表）。
> 全局规范（描边/圆角/阴影/明暗分区）见 [02-视觉风格与主题规格.md](02-视觉风格与主题规格.md)。

## 0. 语义分类

| 语义 | 说明 | 玩家交互 |
|---|---|---|
| `block` 实体障碍 | 立起的物体（树/石柱/建筑），有高度感 | 撞上即死 |
| `terrain` 地形 | 平铺在地表的危险地形（水塘/熔岩/虚空） | 撞上即死（视觉上"踩进去"） |
| `floor` 地板 | 纯背景，无碰撞 | 行走区域 |

> 地形与实体同属 ObstacleEntity（多格任意形状），仅**绘制风格**不同（平铺 vs 立体）与语义标注。

## 1. 地板（Floor，四图各一种）

### 1.1 丛林 · 深绿草地
- 绘制：程序化底纹（叶片暗纹 30 处 + 光斑 12 处，透明度 8~12%）+ 草地斑块点缀（浅绿椭圆 8 处，alpha 0.15）
- 配色：底 `#0e2a1a`，斑块 `#1d4a2e`~`#2e6b3f`
- 细节：无网格感（网格线 alpha 0.18）

### 1.2 地牢 · 石砖地
- 绘制：石砖错缝（砖高 8px，错缝 8px）+ 裂纹 6 条 + 苔藓斑
- 配色：底 `#1a140f`，砖缝 `#000` 50%，苔藓 `rgba(70,110,60,0.35)`

### 1.3 几何 · 渐变网格地
- 绘制：对角渐变（蓝→透明→品红，各 10%）+ 细网格线
- 配色：底 `#191c2b`

### 1.4 深海 · 波纹地
- 绘制：横向正弦波纹 8 条 + 垂直光柱 2 道（8% 白）
- 配色：底 `#0a1e3c`，波纹 `#7fd8ff` 15%

## 2. 实体障碍（block，立体绘制）

> 统一绘制层次：深色底座（20%，覆盖全部碰撞格）→ 椭圆投影 → 本体（轮廓/暗面/主色/亮面/高光）→ 细节动画。

### 2.1 树 tree（丛林）2×2
```
GGGG
GGGG
GGBG
GGBG    (G=树冠 B=树干)
```
- 树冠三层色（深/中/亮）+ 明暗分区 + 叶簇锯齿点 + 果实×3（带高光）
- 动画：树冠轻微摇摆；果实不动

### 2.2 巨石 boulder（丛林）2×1
```
GGGG
GGGG    (椭圆巨石)
```
- 椭圆主体 + 左下暗面 + 裂纹 + 右上高光 + 苔藓点

### 2.3 藤蔓墙 vinewall（丛林）3×1
```
BGBGB
BGBGB    (B=木桩 G=藤蔓)
```
- 木桩×4 + 波浪藤蔓（sin 动画）+ 叶片×5

### 2.4 石柱 pillar（地牢）1×2
```
 T
 T
 S     (T=柱头 S=柱身)
 S
```
- 柱头 + 柱身砖纹 + 高光条 + 裂纹 + 柱基

### 2.5 祭坛 altar（地牢）2×2
```
FF
ST
SS     (F=火焰 T=台面 S=石台)
```
- 基座台阶 + 台体 + 台面 + 脉动符文（火橙发光）+ 火焰摇曳

### 2.6 铁笼 cage（地牢）2×2
```
拱顶
|囚|
|光|
```
- 栅栏 + 横梁 + 顶部拱 + 内部光点脉动 + 锁

### 2.7 大棱柱 prismBig（几何）2×2
```

  ◇
——◇——    (旋转菱形 + 底座)
```
- 底座 + 菱形主体（缓转）+ 高光面 + 顶部悬浮光点

### 2.8 方尖碑 obelisk（几何）1×2
```
  ▲
  ▲
——▲——    (锥体 + 底座)
```
- 锥体 + 侧面高光 + 顶部脉动光点

### 2.9 环形门 ring（几何）3×2
```

| |
| |     (门框 + 门内光膜)
```
- 立柱 + 弧形门楣 + 能量流光点沿弧移动 + 门内光膜（注意：全 6 格碰撞，底座填充保证可见）

### 2.10 珊瑚礁 reef（深海）2×2

——礁——    (基座 + 多枝珊瑚)
```
- 礁石基座 + 分枝×4 + 枝头粉球 + 荧光脉动 + 游鱼影

### 2.11 沉船 wreck（深海）3×2

船体
```
- 倾斜船体弧线 + 甲板木纹 + 破洞 + 斜桅杆 + 海藻覆盖（摆动）

## 3. 地形（terrain，平铺绘制，新增）

> 平铺在地表：无"高度"，绘制 = 地形表面 + 边缘 + 环境细节。形状任意（含 L 形）。
> **对比度标准**：所有地形"底色提亮 + 1~2px 亮色轮廓描边"，与背景色差 ≥30（docs/10 坑 24：深色地形必须肉眼可辨）。

### 3.1 水塘 pond（丛林）2×2 + 岸边
```
~~~~
~~~~     (~=水面)
```
- 深蓝水面 + 波光点（sin 闪烁）+ 岸边亮边 + 底部暗影
- 色：水 `#1a3a5c`，波光 `#8fd8ff`

### 3.2 荆棘丛 brambles（丛林）L 形 3×2
```
XX
XX
XX     (X=荆棘)
```
- 深绿刺丛 + 刺点高光 + 少量浆果红点（警告色）

### 3.3 熔岩裂缝 lavacrack（地牢）3×1
```
~L~
~L~     (L=发光熔岩)
```
- 黑色裂缝 + 橙红发光内核（脉动）+ 火星飘点 + 边缘烧焦暗边

### 3.4 碎石堆 rubble（地牢）L 形 3×2
```
RR
RR
RR     (R=碎石)
```
- 灰碎石块 + 块间深缝 + 顶部高光 + 少量骨白点缀

### 3.5 水晶簇 crystal（几何）不规则 2×2
```
/\  /\
 \/\/     (晶体)
```
- 多根晶柱（青/品红/蓝）+ 棱线高光 + 底部基岩 + 微光脉动

### 3.6 虚空坑 voidpit（几何）实心 3×3
```
###
###
###      (整个坑都是黑洞)
```
- 深黑洞口 + 边缘亮线（青） + 内旋光纹（动画）+ 边缘碎块
- **实心碰撞**：黑洞 = 碰撞区，视觉与碰撞 100% 一致（docs/10 坑 22）

### 3.7 沙洲 sandbank（深海）不规则 3×2
```
sss
s s     (s=沙)
```
- 沙色底 + 斑点纹理 + 湿沙暗边 + 贝壳点（白）

### 3.8 海藻林 kelpfield（深海）L 形 3×2
```
KK
KK
KK     (K=海藻)
```
- 暗绿海藻丛 + 顶部摇曳（sin）+ 气泡点缀

## 4. 动态障碍（motion 不变，docs/02 第 6 节）

| motion | 行为 | 视觉 |
|---|---|---|
| pulse | 原地呼吸 | 藤蔓柱缩放 0.85~1.0（2.5s） |
| gate | 开合闸门 | 关闭时占格（开 1.5s/关 2.5s） |
| patrol | 往返巡逻 | 沿路径移动，棱柱自转 |
| drift | 缓慢漂移 | 水平正弦 ±range，水母触须摆动 |

## 5. 布局约定（docs/09 延续，48×36 网格）

- 密度：实体+地形 ≈ 2.5%（1728 格 ≈ 40 个元素），动态 ≈ 0.5%（8~12 个）
- 布局原则：丛林=均匀散布+中央留空；地牢=走廊式迷宫；几何=中心对称；深海=边缘为主
- 出生点：P1 (3,3)，P2 (44,32)（右下角）；出生点周围 3×3 无碰撞
